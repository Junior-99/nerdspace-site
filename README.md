# NerdSpace public website

Static official landing, support, privacy, deletion, subscription terms and annual Plus account/checkout pages. Source is maintained in NerdSpace’s website/ directory and exported to the dedicated public nerdspace-site repository for free GitHub Pages hosting. No private application source, admin dashboard, provider secret keys or user data are included.

The Plus page uses the public Firebase SDK to sign into an existing verified account. Firebase Functions own pricing, create Paystack checkout and verify signed provider events. No card details enter this website. Native apps purchase through Apple/Google via RevenueCat, not through a web checkout link.

Preview: python -m http.server 5180 --directory website (from the main repository). Original decorative room illustrations are generated by scripts/export-room-artwork.mjs; no publisher promotional artwork is bundled. The unused observatory illustration was generated with the built-in imagegen tool from an original rooftop observatory/cinema concept, with no franchise characters, logos or text.
